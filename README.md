# IT Homelab & Support Portfolio

Welcome to my homelab documentation repository! I am an IT and Cybersecurity student trying to build some hands-on experience in system administration, networking, and IT support.

## 🖥️ Infrastructure Overview
*   **Host OS:** Debian Linux (Headless)
*   **Containerization:** Docker & Docker Compose
*   **Remote Access:** Tailscale (WireGuard VPN)
*   **Firewall:** UFW (Uncomplicated Firewall)

## 🛠️ Deployed Services
*   **GLPI:** ITIL-compliant help desk ticketing system (simulating Tier 1/2 workflows).
*   **Jellyfin:** Media server (testing network throughput and file permissions).
*   **AdGuard Home:** Network-wide DNS and ad-blocker.
*   **Uptime Kuma:** Infrastructure monitoring and alerting.
*   **Portainer:** Docker container management GUI.
